# Doc Break

**Doc Break** is a powerful, PC-level office application designed specifically for Android phones and tablets. It brings advanced desktop-grade document processing, custom equation rendering, and multi-format support right to your mobile device.

---

## 🚀 Key Features

* **PC-Level Productivity:** Built to offer desktop-class document creation and editing experiences on mobile and tablet screens.
* **Custom Equation Rendering:** Advanced math and scientific formula editing capabilities.
* **Pen Sketch Tools:** Integrated freehand drawing and annotation tools for sketches and diagrams.
* **File Directory Access:** Seamlessly manage and open files directly from your local directory structure.
* **Focus Mode:** A clean, distraction-free environment for uninterrupted writing and editing.
* **Multi-Format Export:** Export and save your documents in various formats, including **PDF**.

---

## 📦 Download & Installation

1. Go to the [Releases](../../releases) tab of this repository.
2. Download the latest `.apk` file from the release assets.
3. Install the application on your Android device and start writing!
